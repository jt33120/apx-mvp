- (decision) Three substrate honesties govern every pixel: (1) the corpus is COMPLETE — retenue+ecartee+non-scoree = le corpus, reusing the Epic-2 denominator equation + verdict seal to PROVE the triage sets partition the matter and delete nothing (FR-16/FR-13); (2) the ORDER is a judgement not a proof — a persistent honesty banner carries the Epic-3 truth axis onto triage without borrowing the search badges; (3) retenue/ecartee are DERIVED VIEWS never stored memberships (AD-39) — the cote is a read of (line, pins), NEVER a checkbox.
- (decision) The editable/derived CONTRAST is load-bearing: the confidence cell is READ-ONLY derived (band + dérivée marker, never a field) and sits beside the EDITABLE label select — the affordance difference IS FR-42+FR-40 made visible (scoring and classifying are different acts). A cell edit changes that cell and nothing else; rows never reorder on an edit; re-ranking is a separate explicit act producing a new version that preserves human-set values.
- (decision) THE LINE (Story 4.8, north-star): an ordinal cut drawn BETWEEN two rows (never on a row, never a bare integer), retained above / discarded below (kept/discard tier, distinct from gold), a single gold hairline marking the cut. It SPEAKS the commitment in words ('À mon sens, tout ce qui précède — jusqu'à la pièce n°142') with a stated basis eyebrow (théorie du cas v2, or named intrinsic signals), and is NAMED BY THE LAST RETAINED PIÈCE identity (the substrate's Line(last_retained_piece_id)) — so an import that adds pièces cannot silently move what it designates. Changing the line never reorders the order. The UNSCORED tail is its OWN zone below discarded — never folded in (AD-19/AD-36).
- (decision) PRICED MOVE (Story 4.9): moving the line is priced BEFORE commit — Δ pièces-to-read + Δ estimated prevalence of relevant material in the resulting discarded set ('400 pièces de plus à lire ; part estimée ≈3% → ≈0,4%'). CRITICAL: a PROJECTION register DELIBERATELY DISTINCT from the sampling bound/verdict seal — ink-toned, dashed-edge panel, eyebrow 'PROJECTION DU CLASSEMENT — rien n'a été échantillonné'. A model estimate must NEVER wear a proven bound's clothes (FR-19). Never says 'risque d'avoir manqué' (FR-23, barred). Failure path: no projection → still show pièces-to-read delta, say prevalence unavailable, never invent one.
- (decision) THE PIN (Story 4.11): épingle moves EXACTLY ONE pièce across the line — line unmoved, order unchanged, no other membership changes (FR-43; substrate's Pin applied after the cut, pins_in_force counts only disagreements). MANDATORY one-line reason, recorded as an override (FR-25). Pinned côté badge takes the gold épingle variant (a human override, visually distinct from the line's placement). Reversible; removal is itself a recorded act; pins survive re-ranking marked human-set. JUSTIFICATION (Story 4.6): one line derived from NAMED evidence (retained extracts by chunk id, resolvable to source), each verified by exact containment AT SHOW TIME; a non-resolving extract → shown UNVERIFIED (review-toned), never ordinary (FR-41/FR-11); states source language where it differs (FR-36).

- (decision) THE DRAWER'S FOUR BANDS, in this order, and the order is the argument: (1) LA DÉCISION — the côté (retenue/écartée, a DERIVED view per AD-39) + the derived confidence naming its derivation and its ranking version (AD-23), never a self-reported score; (2) CE SUR QUOI ELLE REPOSE — the retained extracts, each quoting its passage with its chunk identity and source position, each carrying its SHOW-TIME containment verdict; an unresolved extract is review-toned, names its enumerated cause (texte modifié / configuration remplacée / position hors limites / pièce disparue) and is NEVER shown as intact; an intrinsic-only justification is NOT unverified — it shows its named signals and says so; (3) CE QUI SERA ÉCRIT — the proposed audit-record entry, rendered as the row it will become (acte, acteur, horodatage, chaîne, and for an override its ground + the reason it will carry verbatim); (4) CE QUE VOUS POUVEZ FAIRE — reversible actions, each naming its own reversal in the lawyer's language.
- (decision) THE TIER CHOICE IS A FORK, NOT A TOGGLE (FR-26 §11). The export is the ONE act that moves client content out of the firm on purpose, so the surface is a CHOICE SCREEN reached before anything is produced, not a switch on a download button. NUMBERS-ONLY is the default and is described by what it CANNOT carry ('aucun extrait, aucun motif rédigé, aucun nom de fichier'); FULL is described by what it WILL carry, itemised, and requires a second deliberate confirmation naming the recipient-agnostic fact that the file will contain client content. Both tiers state the RBAC scope on their face. Producing either is an audited act (tier, actor, matter, scope, timestamp) — the third named egress path.
- (decision) THE EXPORT'S FIRST PAGE IS A COVER THAT DECLARES ITS OWN LIMITS, before any content: the matter, the RBAC scope it was produced under, the tier, who produced it and when; the CONTINUITY VERDICT PER CHAIN (AD-43) saying which chain a holder of THIS DOCUMENT ALONE can recompute and which was verified inside the system; an AD-35 truncation banner if one is unacknowledged; and DÉGRADÉ stated as a state of the document with its count ('3 extraits ne se résolvent plus') when any retained extract fails at read time (FR-11). Degraded is never a footnote and never a per-row asterisk only.
- (decision) TWO SECTIONS ARE PENDING AND SAY SO (the project's standing rule — asserted with something behind it, or pending with the story that owns it, never faked between). The VALIDATION ACTS section and the ACCEPTED-AS-IS half of the modified-versus-accepted breakdown do not exist until Story 5.8. The export prints both headings with an explicit sentence naming the act as not yet implemented, NOT an empty table and NOT a zero — a zero would read as 'nobody validated anything', which is a finding about the firm rather than about the build.
- (decision) THE DRAWER AND THE EXPORT QUOTE THE BOUND, NEVER RE-ASSEMBLE IT (EXPERIENCE-EPIC5.md's rule, inherited). Same for the OVERRIDE count: it comes from the server counted over the WHOLE trail (5.6), and neither surface recomputes it from what it is currently displaying.
